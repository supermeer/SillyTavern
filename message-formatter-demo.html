🎭 SillyTavern 消息格式化演示

📖 功能说明

这个工具展示了 SillyTavern 中消息的格式化效果。它可以识别并美化以下内容：

*斜体* - 心理活动/动作描述
"引号" - 对话内容
__下划线__ - 强调内容

Markdown 语法支持：

  • *文本* 或 _文本_ → 斜体（心理活动）
  • **文本** → 粗体
  • __文本__ → 下划线
  • ~~文本~~ → 删除线
  • "文本" → "引号"（对话）
  • `代码` → 代码

🔧 技术信息

格式化流程：

  1. 自动修复 Markdown 格式（移除多余空格、补全不配对的标记）
  2. HTML 转义处理（可选）
  3. 识别并转换各种引号类型为 <q> 标签
  4. Markdown 转 HTML（斜体、粗体、下划线等）
  5. 应用 CSS 样式

样式规则：

  • .mes_text em - 斜体使用灰色
  • .mes_text q - 引号使用橙色
  • .mes_text q em - 引号内的斜体继承引号颜色
